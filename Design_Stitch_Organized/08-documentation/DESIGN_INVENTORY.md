## 4. Shared Layouts, Components & Cross-Group Dependencies

Based on direct DOM and CSS analysis across the 51 screen families:

1. **Unified Global Header & Navigation:**
   - Standard in `01-public-marketing`, `03-player-experience` (public views), and authentication entry points.
   - Fixed blur header (`#0A0F35/85`), brand logo, nav links (`Games`, `Tournaments`, `How It Works`, `For Developers`), shimmering CTA button, and user profile pill.
2. **Authenticated App Shell (Sidebar + Topbar):**
   - Standard across `04-developer-workspace`, `05-tournament-host`, and `06-internal-admin`.
   - Shared 260px collapsible sidebar with module navigation, telemetry node status badge (`Riyadh-01 Active`), user profile avatar, and system status indicator.
3. **Tournament Discovery & Detail Sharing:**
   - `tournament_discovery` and `tournament_details_valorant_community_cup` serve both public discovery (Group A) and player bracket registration (Group C). In the archive, discovery is housed in `01-public-marketing` as a public funnel, while deep registration and participant views belong to `03-player-experience`.
4. **Game Testing Detail & Application Sharing:**
   - `game_testing_discovery` is public (Group A), while `game_testing_details_cyber_strike` and `game_testing_application_cyber_strike` are classified under `03-player-experience` as they require gamer rig profiling, passport identity, and NDA cryptographic acceptance.
5. **Smart Escrow & Financial Cards:**
   - Identical UI card patterns for escrow vaults, bounty disbursements, and prize pool splits are shared across `03-player-experience`, `04-developer-workspace` (`payments_earnings`), `05-tournament-host`, and `06-internal-admin` (`finance_management`).
