# React Native Frontend

This is a clean, default cross-platform **React Native** application powered by **Expo SDK 58** and **Expo Router**.

---

## Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Start the development server
```bash
npx expo start
```

### 3. Open on your device or simulator
- Press `w` to open in web browser.
- Press `a` to open on an Android emulator or device.
- Press `i` to open on an iOS simulator.
- Scan the QR code with the Expo Go app on iOS or Android.

---

## Project Structure

- `src/app/`: File-based routes using Expo Router
  - `_layout.tsx`: Root stack navigator layout
  - `index.tsx`: Main home screen
- `assets/`: App icons, adaptive icons, and splash screen
